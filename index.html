Catatan asli

Hash table digunakan untuk lookup cepat. Masalah utama adalah collision. Kita bisa menggunakan chaining atau open addressing. Jika banyak data, fungsi hash epoch semakin penting. Namun, ketika load factor tinggi, performa turun drastis.

Untuk data yang sering dibaca, use separate chaining untuk lebih sederhana. Pada kasus nilai yang sering muncul, gunakan fungsi hash dengan modifikasi pola. Catatan terkait: implementasi di buku “Algoritma dan Struktur Data”.

Versi Sempurna

Ringkasan Eksekutif

Untuk menjaga performa tabel hash, kontrol load factor di sekitar 0.6–0.75, hindari fungsi hash yang terlalu sederhana, dan pilih teknik collision handling yang sesuai dengan pola akses data.

Penjelasan Lengkap

Jika ukuran array tetap dan load factor meningkat, probability collision akan naik secara eksponensial. Dalam praktiknya, array yang terlalu penuh akan membuat time complexity menjadi O(n) di beberapa operasi.

Implementasi Kode
def hitung_hash(kunci, size):
    return kunci % size

class TabelHash:
    def __init__(self, size):
        self.size = size
        self.data = [[] for _ in range(size)]

    def tambah(self, kunci, nilai):
        indeks = hitung_hash(kunci, self.size)
        self.data[indeks].append((kunci, nilai))
